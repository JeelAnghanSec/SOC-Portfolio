
# 🌐 PCAP Analysis

**Turning network traffic into actionable intelligence.**

This directory contains hands-on **PCAP analysis investigations** using **Wireshark** to identify suspicious traffic, malicious activity, network anomalies, and Indicators of Compromise (IOCs).

### 🔍 Core Skills
- 🦈 Wireshark Packet Analysis
- 🌐 Network Traffic Investigation
- 🔎 Protocol & Stream Analysis
- 🕵️ IOC Identification
- ⚔️ Threat & Malware Detection
- 📊 Network Forensics

📂 Each subfolder contains a completed investigation with **analysis, findings, evidence, and screenshots**.

> **Goal:** Capture the evidence. Analyze the traffic. Uncover the threat.
