# 🌐 PCAP Analysis

**Every packet tells a story. This is where I read between the lines.**

Network traffic doesn't lie — it just hides in plain sight. This directory is a collection of hands-on investigations where raw `.pcap` captures are broken down packet-by-packet in **Wireshark** to expose malicious activity, abnormal behavior, and hard Indicators of Compromise (IOCs) buried inside the noise.

No assumptions. No guesswork. Just traffic, timestamps, and truth.

---

### 🔍 Core Skills
- 🦈 **Wireshark Packet Analysis** — filtering signal from noise at the byte level
- 🌐 **Network Traffic Investigation** — mapping conversations, sessions, and flows
- 🔎 **Protocol & Stream Analysis** — following TCP streams to reconstruct intent
- 🕵️ **IOC Identification** — pulling IPs, domains, hashes, and payloads worth flagging
- ⚔️ **Threat & Malware Detection** — spotting C2 beacons, exfil, and lateral movement
- 📊 **Network Forensics** — turning a capture file into a timeline of events

---

### 📂 What's Inside
Each subfolder is a self-contained case file — a real investigation, start to finish, complete with methodology, findings, extracted evidence, and annotated screenshots.

> **Goal:** Capture the traffic. Interrogate the packets. Name the threat.
